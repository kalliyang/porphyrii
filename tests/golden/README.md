# Golden test fixtures

These versioned fixtures support deterministic pronunciation and metrical-quantity tests. They contain public-domain Latin text, openly licensed source material, project-authored annotations, and derived metrical facts.

| File | Purpose | Provenance and license |
|---|---|---|
| `aeneid-1-1-33.txt` | Macronized Aeneid 1.1–33 | David Chamberlain, *Vergil's Aeneid with Macrons and Metrical Scansion*, CC BY 4.0. |
| `aeneid-1-1-7.ipa-gold.json` | Aeneid 1.1–7 pronunciation fixture | Project-authored IPA annotations over Chamberlain's openly licensed text. |
| `aeneid-1-quantity.json` | Aeneid quantity-validation fixture | Project annotations with derived metrical weight patterns from line-by-line Pedecerto comparison. |
| `elegiac-quantity.json` | Elegiac quantity-validation fixture | Public-domain Latin verse with project annotations and derived metrical weight patterns. |
| `la-mapping-v0.1.0.json` | IPA-to-eSpeak mapping fixture | Rule table from classical-cat-dh-lab/espeak-ng-wasm, GPLv3. |

## Pedecerto-derived data

The quantity fixtures retain only derived heavy/light patterns obtained through line-by-line comparison. They contain no Pedecerto response payloads, database records, or redistributed source markup.

## Chamberlain attribution

David Chamberlain (ed.), *Vergil's Aeneid with Macrons and Metrical Scansion*, hypotactic.com, CC BY 4.0. The macron annotations were generated by Johan Winge's latin-macronizer and hand-corrected by the editor.
